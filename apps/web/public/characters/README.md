# Tarot character reference photos

48 licensed reference photographs from Wikimedia Commons, resized and converted
to WebP by Games. These are performer portraits or explicitly labelled cosplay,
not film stills or official character artwork. Character names identify the
reading reference; performer/cosplay captions identify the person photographed.
Each image keeps its source license; share-alike images remain under that license.
Complete creator attribution, file pages, license URLs and remote sources live in
[manifest.json](manifest.json). No question or reading was sent to Wikimedia.

Chihiro uses Daveigh Chase, explicitly labelled English voice; the cast relation is
confirmed by [Disney D23](https://d23.com/a-to-z/spirited-away-film/).
Link and Princess Peach use clearly identified convention cosplay photographs.
Photographs are used for character-reference context, without implying endorsement.
