# Expanded source-linked reference artwork

This version contains **5,588 accepted images**, joined by stable ID to the 5,636-reference active catalogue together with the preserved original 48. All additions have `reviewStatus: accepted`, exact hashes, measured dimensions and source or generation provenance.

- `manifest.json`: active accepted image records. 5,551 are sourced and 37 are clearly labelled original illustrations.
- `review.json`: preserves the historical first-stage exclusions/crops and records final recovery, group/editorial holds and the frozen candidate hash.
- `archive/`: the superseded Nightwing mantle image, preserved outside the eligible count; explicit Dick Grayson now owns the Nightwing lookup aliases.
- Ordinary images are 320×400 WebP; 24 specific meme variants may retain 320×240 scenes. Total added image bytes: 86,056,106.
- Person/character/religious depiction, source artwork reference, generated illustration and meme are distinct image contracts. Calligraphy retains complete lettering and an explicit artwork-reference title. Historical depictions and generated illustrations never claim authenticated facial likenesses.
- Original48 imagery and older performer/cosplay archives are unchanged. Metadata records actual source credits and declared licences; it does not invent permissions.

The importer uses bounded cached intake and atomic checkpoints. A bad source image creates a repair task, not a permanent ban on its identity. Every final image is manually reviewed before export. The exporter validates exact hashes, dimensions, canonical entity joins, required attribution and review acceptance. Full factual contexts remain server-side.

Local promotion, exporter drift, index integrity, importer compile and Ruff checks pass. Push/deployment/live status is recorded by the release task.
