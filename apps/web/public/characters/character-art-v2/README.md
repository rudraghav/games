# Tarot actual-character artwork v2

48 local images depict the fictional characters themselves: official character
art, in-character film/TV stills or character illustrations. Performer headshots
and cosplay are excluded from this active set. The original photo ledger and
files remain archived one directory above; they are not UI fallbacks.

All delivery files use a reviewed 400×500 frame. Crops keep the intended
character visible; transparent art uses a warm ivory ground. Source watermarks
are retained. Images are resized and converted to WebP.

## Sources and rights

These are sourced online images, not generated illustrations or a free asset
kit. Copyrighted references retain their original rights; attribution does not
grant an open reuse license. The manifest distinguishes copyright references,
CC-licensed artwork and public-domain material. CC artwork retains its source
license. Character rights and any underlying work rights remain separate.

The built-in image tool rejected one character-illustration attempt; no generated
output was used and no other image provider was used to bypass that rejection.
